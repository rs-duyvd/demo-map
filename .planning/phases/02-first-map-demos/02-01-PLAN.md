  <action>
Create `app/pages/leaflet.vue` as a single-file Vue component. The complete structure:

**Script setup section:**
- First line: `definePageMeta({ ssr: false })` — disables SSR for this page (LEAF-01)
- Import `onMounted`, `onUnmounted`, `ref`, `shallowRef` from `'vue'`
- Import `useMarkerData` from `'~/composables/useMarkerData'`
- Import `type { MarkerData }` from `'~/types/marker'`
- Declare `mapContainer = ref<HTMLElement | null>(null)` — template ref for the map div
- Declare `mapInstance = shallowRef<import('leaflet').Map | null>(null)` — shallowRef to avoid Vue proxy on Leaflet internals
- Declare `selectedMarker = ref<MarkerData | null>(null)` — controls MarkerDialog visibility
- Declare `leafletVersion = ref('')` — populated after dynamic import
- Call `const markers = useMarkerData()` to get all 10 POI markers

**onMounted (async):**
- Dynamic import: `const L = (await import('leaflet')).default`
- Set version: `leafletVersion.value = (await import('leaflet')).version` — fallback to `L.version` if available
- Actually, import once: `const leafletModule = await import('leaflet')`, then `const L = leafletModule.default`, `leafletVersion.value = leafletModule.version`
- Create map: `L.map(mapContainer.value!, { center: [16.0, 107.0], zoom: 6, zoomControl: true })` (LEAF-05 zoom controls)
- Add tile layer: `L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', { attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors', maxZoom: 19 }).addTo(mapInstance.value)` (LEAF-02)
- Loop through markers and for each POI create:
  - `L.divIcon({ html: '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 36" width="24" height="36"><path d="M12 0C5.373 0 0 5.373 0 12c0 9 12 24 12 24s12-15 12-24C24 5.373 18.627 0 12 0z" fill="#2563eb"/><circle cx="12" cy="12" r="5" fill="white"/></svg>', className: '', iconSize: [24, 36], iconAnchor: [12, 36] })` (LEAF-03 — custom SVG, className: '' removes default white box)
  - `L.marker([poi.lat, poi.lng], { icon }).on('click', () => { selectedMarker.value = poi }).addTo(mapInstance.value!)` (LEAF-04 click handler)

**onUnmounted:**
- `mapInstance.value?.remove()` — destroys Leaflet instance, clears container _leaflet_id (LEAF-07)
- `mapInstance.value = null`

**Template section (top to bottom per UI-SPEC Layout Contract):**
1. Page header: `<div class="h-16 bg-white border-b border-gray-200 flex items-center px-8">`
   - Left: `<NuxtLink to="/" class="text-sm text-gray-500 hover:text-gray-900">← Home</NuxtLink>`
   - Center (flex-1 text-center): `<span class="text-sm font-semibold text-gray-900">Leaflet Demo</span>`
   - Right: empty `<div class="w-16"></div>` for balance
2. Map container wrapper: `<div class="relative">`
   - Version badge: `<div class="absolute top-4 left-4 z-10 bg-white/90 backdrop-blur-sm rounded-lg px-3 py-2 shadow-sm">` containing `<span class="text-xs font-semibold text-gray-700">Leaflet</span><span class="text-xs text-gray-400 ml-1">v{{ leafletVersion }}</span>` (LEAF-06)
   - Map div: `<div ref="mapContainer" class="w-full h-[calc(100vh-64px)]"></div>` — explicit height prevents 0px collapse (LEAF-02)
3. MarkerDialog: `<MarkerDialog :marker="selectedMarker" @close="selectedMarker = null" />` (LEAF-04)
