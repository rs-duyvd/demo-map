Create `app/pages/maplibre.vue` as a single-file Vue component. Follow the same page structure as leaflet.vue for visual consistency, but use MapLibre GL JS APIs.

**Script setup section:**
- First line: `definePageMeta({ ssr: false })` — disables SSR (MAPLIBRE-01)
- Static imports (safe because page is CSR-only):
  - `import { onMounted, onUnmounted, ref, shallowRef } from 'vue'`
  - `import { Map, Marker, NavigationControl, version as maplibreVersion } from 'maplibre-gl'` (MAPLIBRE-06 version)
  - `import 'maplibre-gl/dist/maplibre-gl.css'` — static import is safe here, page has ssr: false
  - `import { useMarkerData } from '~/composables/useMarkerData'`
  - `import type { MarkerData } from '~/types/marker'`
- Declare `mapContainer = shallowRef<HTMLElement | null>(null)` — template ref for map div (shallowRef for DOM element)
- Declare `mapInstance = shallowRef<Map | null>(null)` — MUST be shallowRef, NOT ref (MAPLIBRE-02, prevents Vue from traversing WebGL object graph)
- Declare `selectedMarker = ref<MarkerData | null>(null)` — controls MarkerDialog visibility
- Call `const markers = useMarkerData()` to get all 10 POI markers

**CRITICAL: MapLibre uses [lng, lat] order, NOT [lat, lng] like Leaflet. The MarkerData type has separate .lat and .lng fields. Always pass [poi.lng, poi.lat] to MapLibre APIs.**

**onMounted:**
- Create map instance:
  ```
  mapInstance.value = new Map({
    container: mapContainer.value!,
    style: 'https://tiles.openfreemap.org/styles/liberty',
    center: [107.0, 16.0],   // [lng, lat] — Vietnam center
    zoom: 5,
  })
  ```
  (MAPLIBRE-01 — OpenFreeMap liberty style, no API key needed)
- Add navigation control: `mapInstance.value.addControl(new NavigationControl(), 'top-right')` (MAPLIBRE-05)
- Loop through markers and for each POI:
  - Create custom element: `const el = document.createElement('div')`
  - Set innerHTML to the same SVG pin used in Leaflet: `el.innerHTML = '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 36" width="24" height="36"><path d="M12 0C5.373 0 0 5.373 0 12c0 9 12 24 12 24s12-15 12-24C24 5.373 18.627 0 12 0z" fill="#2563eb"/><circle cx="12" cy="12" r="5" fill="white"/></svg>'` (MAPLIBRE-03)
  - Set cursor: `el.style.cursor = 'pointer'` (accessibility per UI-SPEC)
  - Add click listener: `el.addEventListener('click', () => { selectedMarker.value = poi })` (MAPLIBRE-04)
  - Create marker: `new Marker({ element: el }).setLngLat([poi.lng, poi.lat]).addTo(mapInstance.value!)` — NOTE: [lng, lat] order

**onUnmounted:**
- `mapInstance.value?.remove()` — destroys WebGL context, detaches all listeners (MAPLIBRE-07)
- `mapInstance.value = null`

**Template section (must match leaflet.vue header structure for visual consistency):**
1. Page header: `<div class="h-16 bg-white border-b border-gray-200 flex items-center px-8">`

   - Map div: `<div ref="mapContainer" class="w-full h-[calc(100vh-64px)]"></div>` — explicit height prevents 0px collapse
3. MarkerDialog: `<MarkerDialog :marker="selectedMarker" @close="selectedMarker = null" />` (MAPLIBRE-04)
